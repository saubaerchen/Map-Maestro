# Scouting Sample Logic

## Map Selection

Only analyse maps that Vincent has **explicitly stated are important** for the current scouting target. Never infer or assume map relevance. If in doubt, ask.

> Example: Haven is NOT included unless Vincent says so.

The relevant map list will differ per team and per tournament phase. Always confirm with Vincent before running analysis on a new team.

---

## Sample Size Rules

### Rule A — Primary window

Collect **all matches from 2026-04-01 onwards** on the relevant maps.

### Rule B — Minimum sample supplement

If a map has **fewer than 3 games** from 2026-04-01 onwards, go back in time (before 2026-04-01) and add the **most recent games** for that map until the total reaches **3**.

Stop supplementing as soon as you hit 3. Do not add more than needed.

---

## Applied Example — SGE Split

- April 1st onwards: 2 Split games (vs ATN 2026-04-07, vs RZN 2026-04-14)
- 2 < 3 → Rule B applies
- Most recent pre-April-1st Split: 2026-03-21 vs TL
- Final sample: **3 Split games** (2026-03-21, 2026-04-07, 2026-04-14)
